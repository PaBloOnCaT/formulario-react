# Backend - Node + Express + MySQL

1. Ejecutar `db.sql` en MySQL (Workbench o consola) para crear la base `formulario` y la tabla `usuarios`.
2. Poner tu clave de MySQL en `config/db.js`.
3. Instalar y correr:

       npm install
       npm start

Endpoints: GET/POST `/usuarios`, GET/PUT/DELETE `/usuarios/:id`
